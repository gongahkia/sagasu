YOUR OWN LITTLE CAMPUS COMPANION

Bring Sagasu
to your chat.

The public website shows daily, read-only snapshots. Your personal Telegram bot can search on demand and book a room after you review and explicitly confirm it.

You run your own instance with your own Telegram token and SMU session. Microsoft password entry and MFA happen in your local Chrome window. Keep the computer running while you use the bot.

01 / Get the essentials

You need Python 3.12, Git, Google Chrome, a Telegram account, and an SMU account with FBS access. In Telegram, open @BotFather, send /newbot, and keep the returned token private. Find your numeric Telegram user ID using @userinfobot.

02 / Install Sagasu

git clone https://github.com/gongahkia/sagasu.git
cd sagasu
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chrome
cp .env.example .env

On Windows, activate with .venv\Scripts\activate. Installing the Playwright Chrome channel may install or update Google Chrome.

03 / Make it personal

Edit your local .env. Set BOT_TOKEN to the token from BotFather and TELEGRAM_OWNER_ID to your numeric user ID. Optionally set SMU_LOGIN_EMAIL to prefill your username. The personal bot does not need a saved SMU password.

BOT_TOKEN=your-private-bot-token
TELEGRAM_OWNER_ID=your-numeric-user-id
SMU_LOGIN_EMAIL=your.name@smu.edu.sg

Keep .env, bot/.fbs-profile/, and bot/bot_state.pickle private. Never commit or share them. The browser profile contains your signed-in session.

04 / Find your first room

python -m bot.bot
  1. Open your new bot in Telegram and send /start.
  2. Use /config to choose your date, time, buildings, and room filters.
  3. Choose “Find available rooms.” If prompted, complete Microsoft login and MFA in Chrome on the computer running the bot.
  4. Select a room or auto-pick, then send /book Project meeting | friend@smu.edu.sg.
  5. Review your details. “Validate only” prepares the form without submitting. “Confirm & book” submits and checks My Bookings.

A few useful commands

/status shows settings and the selected room. /help shows the flow. /logout clears Telegram search and booking state; sign out in Chrome separately to end the SMU session.

If something needs attention

No response? Check that the process is running, your token is correct, and the configured owner ID matches your account. Login expired? Search again and complete the Chrome prompts. FBS layout changed? The browser automation may need an update. If a booking outcome is unclear, check My Bookings in FBS before retrying.

Hosting the public daily snapshot is a separate workflow. See the repository’s website deployment guide ↗ for GitHub Actions and Pages setup.
